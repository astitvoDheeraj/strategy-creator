This module scans active NIFTY 200 members only on the completed 09:15 IST 5-minute candle (candle OPEN time). A short setup requires high above SMA20, SMA50, and SMA200 and close below all three. A long setup requires a bullish body opening below and closing above all three SMAs, with volume strictly greater than the preceding candle's volume. Both setups require the preceding candle's SuperTrend within the current candle's low-to-high range, inclusive. All conditions within either setup must hold; the setups are alternatives, not simultaneous requirements. Indicators use the stored platform defaults, including SuperTrend (10, 3).

Before liquidity ranking, a long setup must also close strictly above all three SMAs and the current SuperTrend; a short setup must close strictly below all three SMAs and the current SuperTrend. Equality, missing indicators, or mixed direction excludes the stock. When multiple stocks qualify at 09:15 IST, only the highest-liquidity stock across both long and short setups is retained. Each date returns at most one stock; dates without an opening qualifier return no row, and later candles are never eligible. The liquidity proxy is average daily volume / (1 + average daily relative range), where relative range is (daily high - daily low) / daily close. It uses stored `daily` candles for the preceding `liquidity_days` trading sessions (default 10, configurable from 1 to 90), excluding the signal day. Missing history fails the scan rather than silently choosing a winner. A lone opening qualifier bypasses ranking; ties use signal volume, then symbol.

By default the scan covers the latest 60 trading sessions. `/strategy-api/94d20366/scan` supports inclusive `from_date`/`to_date` (YYYY-MM-DD, at most 90 calendar days), `as_of` (YYYY-MM-DDTHH:MM, IST), and `symbols` (comma-separated, intersected with live NIFTY 200). Existing `limit` (1–10) and sort overrides remain accepted for compatibility but cannot change the single daily liquidity winner. Queries load only the opening candle for each trading day plus the preceding candle per stock. Rows include `scan_date` and `interval`, newest date first; `total` counts selected daily winners. The `Signal` column displays `LONG` when the close is above SuperTrend and all three SMAs, and `SHORT` when it is below SuperTrend and all three SMAs; these values use translucent green and red backgrounds respectively. Presentation requests a flat table with `group_by_date: false` and `date_chips: false`, keeping the top date-range filter, symbol search, sortable columns, and numbered pagination (10 rows per page). Explicit replay includes the target candle after completion and excludes later OPEN timestamps; live scans exclude the unfinished 5-minute candle. Only interval `5` is supported. `/strategy-api/94d20366/health` is unchanged.

Screen with Direction is always enabled. Every match includes uppercase `direction`: `BUY` when the signal candle close is strictly above current SuperTrend and SMA20, SMA50, and SMA200; `SELL` when strictly below all four; otherwise `NEUTRAL` (including equality, missing indicators, or mixed relationships). This uses the same candle indicators as `signal`, without changing match eligibility or liquidity ranking. The `direction` column uses format `direction` immediately after `stock`, and `/scan` echoes the enabled flag and buy/sell/neutral rules in its top-level `direction` object.
