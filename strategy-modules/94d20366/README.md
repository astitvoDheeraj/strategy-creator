This module scans active NIFTY 200 members for the first completed 5-minute candle (OPEN timestamp 09:15 IST) whose high is above SMA20, SMA50, SMA200, and current SuperTrend, and whose close is below all four indicators. Previous SuperTrend must be below the current close. Indicators use the stored platform defaults, including SuperTrend (10, 3).

When multiple stocks qualify on a date, only the highest-liquidity stock is returned. The liquidity proxy is average daily volume / (1 + average daily relative range), where relative range is (daily high - daily low) / daily close. It uses stored `daily` candles for the preceding `liquidity_days` trading sessions (default 10, configurable from 1 to 90), excluding the signal day. Missing history fails the scan rather than silently choosing a winner. A lone qualifier bypasses ranking; ties use signal volume, then symbol.

By default the scan covers the latest 60 trading sessions. `/scan` supports inclusive `from_date`/`to_date` (YYYY-MM-DD, at most 90 calendar days), `as_of` (YYYY-MM-DDTHH:MM, IST), `symbols` (comma-separated, intersected with live NIFTY 200), a per-date `limit`, and sort overrides. Rows include `scan_date` and `interval`, newest date first; `total` counts qualifying stocks before ranking/capping. Explicit replay includes the target candle after completion and excludes later OPEN timestamps; live scans exclude the unfinished 5-minute candle.
