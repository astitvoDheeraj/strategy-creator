This module scans active NIFTY 200 members for the first 5-minute candle at 09:15 IST whose high is above and close below SMA20, SMA50, SMA200, and SuperTrend, with the previous SuperTrend below the close and the current SuperTrend above it; by default it scans the latest 60 trading sessions and supports an inclusive date range, IST replay cutoff, symbol restriction, per-date limit, and sort override.
