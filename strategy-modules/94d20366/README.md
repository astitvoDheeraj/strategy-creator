This module scans active members of the selected universe (NIFTY 200 by default) only on the completed 09:15 IST 5-minute candle (candle OPEN time). A short setup requires high above SMA20, SMA50, and SMA200 and close below all three. A long setup requires a bullish body opening below and closing above all three SMAs, with volume strictly greater than the preceding candle's volume. Both setups require the preceding candle's SuperTrend within the current candle's low-to-high range, inclusive. All conditions within either setup must hold; the setups are alternatives, not simultaneous requirements. Indicators use the stored platform defaults, including SuperTrend (10, 3).

Before ranking, a long setup must also close strictly above all three SMAs and the current SuperTrend; a short setup must close strictly below all three SMAs and the current SuperTrend. Equality, missing indicators, or mixed direction excludes the stock. When multiple stocks qualify at 09:15 IST, select the stock combining medium liquidity and medium signal-candle range across both long and short setups. Each date returns at most one stock; dates without an opening qualifier return no row, and later candles are never eligible. The liquidity proxy remains average daily volume / (1 + average daily relative range), where relative range is (daily high - daily low) / daily close. It uses stored `daily` candles for the preceding `liquidity_days` trading sessions (default 10, configurable from 1 to 90), excluding the signal day. Missing or invalid history fails the scan rather than silently choosing a winner.

Signal-candle range (%) is `100 * (high - low) / close` of the qualifying 09:15 candle, not its historical daily range. “Medium” is relative to that date's qualifying stocks, not an absolute liquidity or volatility band. Rank each metric from 0 to 1 with tied values sharing the midpoint of their ranks; minimize `(liquidity_percentile - 0.5)² + (range_percentile - 0.5)²`. This weights the two metrics equally regardless of units and selects the closest combined middle candidate even when no stock is exactly medium in both. Ties prefer higher liquidity, then higher signal volume, then lexicographically greater symbol. With two qualifiers both are equally central, so these tie-breakers apply. A lone opening qualifier bypasses history ranking as before and reports `liquidity: null`. Rows and columns expose `liquidity` (the historical proxy) and `signal_range_pct` so the measurements can be inspected.

By default the scan covers the latest 60 trading sessions. `/strategy-api/94d20366/scan` supports inclusive `from_date`/`to_date` (YYYY-MM-DD, at most 90 calendar days), `as_of` (YYYY-MM-DDTHH:MM, IST), and `symbols` (comma-separated, intersected with the selected live universe). Existing `limit` (1–10) and sort overrides remain accepted for compatibility but cannot change the single daily combined-metric winner. Queries load only the opening candle for each trading day plus the preceding candle per stock. Rows include `scan_date` and `interval`, newest date first; `total` counts selected daily winners. The `Signal` column displays `LONG` when the close is above SuperTrend and all three SMAs, and `SHORT` when it is below SuperTrend and all three SMAs; these values use translucent green and red backgrounds respectively. Presentation requests a flat table with `group_by_date: false` and `date_chips: false`, keeping the top date-range filter, symbol search, sortable columns, and numbered pagination (10 rows per page). Explicit replay includes the target candle after completion and excludes later OPEN timestamps; live scans exclude the unfinished 5-minute candle. Only interval `5` is supported. `/strategy-api/94d20366/health` is unchanged.

The `universe` query parameter defaults to `nifty_200` and accepts one or more comma-separated values from `nifty_200`, `nifty_50`, `nifty_next_50`, `nifty_100`, `nifty_500`, `nifty_midcap_50`, `nifty_midcap_100`, `nifty_midcap_150`, `nifty_smallcap_50`, `nifty_smallcap_100`, and `nifty_smallcap_250`. Multiple values scan the union of active members, for example `/strategy-api/94d20366/scan?universe=nifty_50,nifty_100`. `all` or an explicitly empty value (for example `?universe=`) scans all stocks with candles without querying `universe_members`; omitting the parameter uses NIFTY 200. If any requested ID is unknown, the scan falls back to `nifty_200`. Symbol filters are applied after universe selection. The response exposes the parameter's multi-value choices and names the selected universe(s) in `criteria`.

Screen with Direction is always enabled. Every match includes uppercase `direction`: `BUY` when the signal candle close is strictly above current SuperTrend and SMA20, SMA50, and SMA200; `SELL` when strictly below all four; otherwise `NEUTRAL` (including equality, missing indicators, or mixed relationships). This uses the same candle indicators as `signal`, without changing match eligibility or combined ranking. The `direction` column uses format `direction` immediately after `stock`, and `/scan` echoes the enabled flag and buy/sell/neutral rules in its top-level `direction` object.
