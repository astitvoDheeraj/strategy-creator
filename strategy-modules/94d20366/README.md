This module scans active NIFTY 200 members on every completed 5-minute candle. A short setup requires high above SMA20, SMA50, and SMA200 and close below all three. A long setup requires a bullish body opening below and closing above all three SMAs, with volume strictly greater than the preceding candle's volume. Both setups require the preceding candle's SuperTrend within the current candle's low-to-high range, inclusive. All conditions within either setup must hold; the setups are alternatives, not simultaneous requirements. Indicators use the stored platform defaults, including SuperTrend (10, 3).

When multiple stocks qualify at 09:15 IST (candle OPEN time), only the highest-liquidity opening stock is retained. Later candles remain eligible for every stock. The liquidity proxy is average daily volume / (1 + average daily relative range), where relative range is (daily high - daily low) / daily close. It uses stored `daily` candles for the preceding `liquidity_days` trading sessions (default 10, configurable from 1 to 90), excluding the signal day. Missing history fails the scan rather than silently choosing a winner. A lone opening qualifier bypasses ranking; ties use signal volume, then symbol.

By default the scan covers the latest 60 trading sessions. `/scan` supports inclusive `from_date`/`to_date` (YYYY-MM-DD, at most 90 calendar days), `as_of` (YYYY-MM-DDTHH:MM, IST), `symbols` (comma-separated, intersected with live NIFTY 200), a per-date `limit` (1–10), and sort overrides. Queries load one trading day at a time plus the preceding candle per stock. Retain each stock's highest-volume eligible candle per day, breaking volume ties by latest candle time. Rows include `scan_date` and `interval`, newest date first; `total` counts unique qualifying stock/date pairs before ranking/capping. Explicit replay includes the target candle after completion and excludes later OPEN timestamps; live scans exclude the unfinished 5-minute candle. Only interval `5` is supported.

The report is written to `ACCEPTANCE_REPORT_PATH` (default `acceptance_report.json` beside the test), with measured conditions and actual returned rows normalized to epoch seconds. Run `python -m pytest -vv test_scan.py` for focused regressions. Passing the marked examples does not establish profitability or future signal correctness.
