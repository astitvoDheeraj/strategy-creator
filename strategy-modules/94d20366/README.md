This module scans active NIFTY 200 members for the first 5-minute candle at 09:15 IST whose high is above SMA20, SMA50, SMA200, and the previous SuperTrend, and whose close is below those averages and the current SuperTrend; the prior candle must have closed above its SuperTrend. By default it scans the latest 60 trading sessions and supports an inclusive date range, IST replay cutoff, symbol restriction, per-date limit, and sort override.
